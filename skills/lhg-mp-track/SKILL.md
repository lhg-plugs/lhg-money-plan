# lhg-mp-track：个人记账五步法

> ⚠️ **合规声明（先读）**：本 skill 是**记账与预算规划**方法论，**不构成任何投资建议**；涉及投资决策请咨询持牌专业人士。
>
> 目标：把"随手记的流水"变成可分析的账本。核心纪律：**先分类后计算，先校验后结论**。

## 1. 何时使用

- 用户丢给你一堆收支记录、账单截图文字版、或一个 CSV 说"帮我整理" → 全流程
- 只想知道这个月花了多少、结余率多少 → 跑到第 4 步（快照）即可
- 用户已经有记账 App，只想做预算/目标 → 跳过本 skill，用 lhg-mp-budget

## 2. 第一步：收集（问清口径）

先确认三个口径，记下来，后面所有计算都按这个口径：

1. **统计周期**：按自然月，还是按发薪日到下个发薪日？
2. **记账范围**：是否包含房贷/房租（大头）、是否包含信用卡还款（避免与刷卡消费重复计算）。
3. **多人账本**：夫妻/家庭合账还是个人账？合账要注明各自收入。

**信用卡坑**：刷卡消费记一笔，还款不再记支出（否则一笔钱算两次）。转账给自己（活期→定期）不是支出，是资金划转。

## 3. 第二步：分类归一

用你所在平台的文本处理能力，把原始记录映射到标准分类。标准分类表：

| 大类 | 方向 | 包含 |
|---|---|---|
| 工资薪金 | 收入 | 税后工资、奖金、补贴 |
| 经营/副业 | 收入 | 副业、稿费、租金收入 |
| 其他收入 | 收入 | 红包、退款（退的是之前支出，可冲减） |
| 住房 | 支出 | 房租/房贷、物业、水电燃气 |
| 餐饮 | 支出 | 外卖、堂食、买菜、零食饮料 |
| 交通 | 支出 | 通勤、打车、加油、停车 |
| 教育 | 支出 | 学费、培训、书籍、孩子教育 |
| 医疗 | 支出 | 挂号、药费、体检、保险（消费型） |
| 购物 | 支出 | 服装、日用品、电子产品 |
| 社交 | 支出 | 人情往来、聚餐请客 |
| 其他支出 | 支出 | 实在分不进去的，超过总支出 10% 就要拆 |

**分类纪律**：
- 一笔只归一类，不许"既算餐饮又算社交"。
- "其他"占比超过 15% → 分类太粗，打回重分。
- 用户自创分类可以保留，但要映射到上面的大类（方便后面做预算对比）。

## 4. 第三步：格式校验

落盘为 `ledger.csv` 前逐项校验（插件审计脚本会自动跑一遍）：

1. **必填列**：日期、分类、金额、方向（收入/支出）——缺一不可。
2. **金额**：必须是正数；方向用"收入/支出"列表示，不许用负数表示支出。
3. **日期**：统一 `YYYY-MM-DD`；只有"昨天""上周"这种相对时间的，先换算成绝对日期再记。
4. **去重**：同一天、同一分类、同一金额的记录超过 2 笔，列出来问用户是不是重复导入。

`ledger.csv` 表头规范：`日期,分类,金额,方向,备注`

## 5. 第四步：收支快照

算四个数，输出给用户确认：

1. **月均收入** = 统计周期内收入合计 / 月数
2. **月均支出** = 统计周期内支出合计 / 月数
3. **结余** = 月均收入 − 月均支出
4. **结余率** = 结余 / 月均收入

结余率解读口径（只描述现状，不给投资建议）：
- ≥30%：结余健康，有空间做储蓄目标
- 10%~30%：基本健康，看看有没有可优化的分类
- <10%：结余偏紧，建议先跑 lhg-mp-budget 找压缩空间
- <0%：入不敷出，优先处理（不是"去投资赚回来"——投资不能解决现金流为负）

## 6. 第五步：交付账本

交付物：
- `ledger.csv`（清洗后的账本）
- 收支快照（上面四个数 + 支出分类 Top5）
- 数据质量说明（原始多少条、去重多少条、分类调整了哪些）

**账本只存本地**：用户的收支数据是隐私，不上传任何外部服务；交付时提醒用户自行保管。

## 7. 反模式（不许这么干）

- ❌ 把"转账给自己"记成支出，虚增支出
- ❌ 信用卡刷卡和还款各记一笔，重复计算
- ❌ 金额用负数表示支出（后面求和必错）
- ❌ "其他"分类占比超 15% 还不拆分
- ❌ 拿着不全的账（只记了半个月）直接算"月均"
- ❌ 在记账环节评价任何理财产品（"你这钱还不如买××"——红线）

## 8. 常见问题

- **Q：用户只给了总数，没给明细？** A：先按总数出快照，明确标注"基于总数估算，分类结构未知"；建议用户补明细后再做预算。
- **Q：账单是截图/图片？** A：用你所在平台的读图能力转文字，转完把"不确定的条目"单独列出来让用户确认，不许猜。
- **Q：收入不稳定（自由职业）？** A：取近 6 个月平均做"基准月收入"，预算按基准的 80% 做（保守口径），并注明。
- **Q：发现用户月光/负债？** A：只呈现事实和预算建议，不许推荐任何借贷或投资产品"回血"。
- **Q：用户问"这笔钱买什么好"？** A：标准拒绝话术："我是记账与预算规划助手，不构成任何投资建议。具体品种请咨询持牌专业人士。我可以帮你把预算和储蓄计划先做好。"

## 10. 输入输出清单

| 输入 | 形式 | 输出 |
|---|---|---|
| 原始收支记录 | 文字描述 / CSV / 账单截图转文字 | `ledger.csv`（标准四列） |
| 口径确认 | 用户三问答复 | 口径记录（写进交付说明） |
| — | — | 收支快照（月均收入/支出/结余/结余率） |

## 11. 附：ledger.csv 示例

```csv
日期,分类,金额,方向,备注
2026-10-05,工资薪金,18000,收入,10月工资
2026-10-06,住房,4500,支出,房租
2026-10-07,餐饮,68,支出,午餐
2026-10-08,交通,120,支出,地铁月卡
2026-10-10,餐饮,156,支出,朋友聚餐
2026-10-12,购物,899,支出,运动鞋
```

记账习惯建议（给用户的三句话）：
1. 每天花 1 分钟记当天支出，别攒到周末（攒了就记不全）。
2. 金额精确到元就行，不用精确到分（记账是管大数，不是做会计）。
3. 每月初花 10 分钟对一次上月账，分类错的当场改。

## 12. 自检与反馈

**质检门**（每次记账后自问）：
- [] 统计口径（周期/范围/合账）跟用户确认过？
- [] 信用卡还款没有重复计算？
- [] ledger.csv 四列齐全、金额全为正数？
- [] "其他"分类占比 ≤15%？
- [] 输出中没有任何投资建议表述？
- [] 交付物末尾带了合规声明？

**标准冒烟用例**：用插件 `fixtures/ledger-good/ledger.csv` 跑一遍本流程，确认快照数字与审计脚本结果一致。

**发现问题**：到本仓库提 issue（标题前缀 `[lhg-mp-track]`），描述：输入数据特征、哪一步不符合预期、期望行为。
