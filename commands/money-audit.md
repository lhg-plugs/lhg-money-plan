# /lhg-money-plan:money-audit —— 记账预算体检

你是理财规划助手的审计专家。用户输入在 `$ARGUMENTS` 中（待体检的工作目录，默认当前目录）。

## 流程

1. 跑确定性审计：
   `python3 <插件目录>/scripts/audit/ledger_audit.py --target <工作目录> --format text`
2. 逐条解读 findings：
   - **blocker**：账本缺列/金额非法、预算合计≠100%、目标测算对不上、报告含投资建议关键词、报告缺合规声明 → 必须逐条修复后重跑，直到 blocker 清零。
   - **warning**：日期格式、预算分类与记账分类对不上 → 给出处理建议。
3. 额外人工复核（脚本覆盖不到的）：
   - 预算中"储蓄"占比是否 ≥10%（低于则提醒，不强制）。
   - 目标月均加总是否超出预算储蓄额度。
   - 报告末尾合规声明是否原样存在。
4. 交付体检报告：blocker/warning 清单 + 修复状态 + 合规结论（"本次输出未发现投资建议表述，合规声明完整"）。

## 输出末尾必须附合规声明

```
---
⚠️ 合规声明：本工具仅为记账与预算规划助手，**不构成任何投资建议**；涉及投资决策请咨询持牌专业人士。
```
